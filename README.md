# Ava Watson — personal portfolio

A responsive, accessible, single-page portfolio for Ava Watson, a Communications student at Tulane University interested in marketing, advertising, film, and media.

## Publish with GitHub Pages

The site is static and needs no build step. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/(root)` folder, then save. GitHub Pages will publish `index.html` at the repository’s Pages URL.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive visual design and reduced-motion support
- `script.js` — accessible mobile navigation and current-year footer
- `assets/` — original SVG artwork and favicon

## Personalize before sharing

The page intentionally avoids inventing work history, projects, contact details, or social accounts. The contact section directs visitors to the contact information on Ava’s resume. Add a preferred email or professional profile link there if you want visitors to contact you directly from the site. The display fonts load from Google Fonts when online; the design falls back to system fonts if they are unavailable.
